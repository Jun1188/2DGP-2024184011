소닉 애니메이션 뷰어 작성

개발언어 python
라이브러리 pico2d
파일 이름 sonic_animation_viewer.py
단일 파일로만 작성
스프라이트 이미지 sonic-sprite.png

기능
이미지의 모든 동작을 재생
동작별 5회 재생, 1초 쉬고 그다음 동작 재생
모든 동작을 다 재생한 뒤, 다시 무한반복

화면 대비 이미지가 잘 보이게 충분히 객체를 확대

개발 방법:
힌번에 작성하지 말고 단계별로 작성, 각 단계마다 커밋하기
동작 구분
같은 행이라도 서로 다른 동작은 독립된 action으로 구분한다.
기존 action 8(이미지 8번째 행)은 앞 6프레임과 뒤 2프레임으로 분리한다.
기존 action 10(이미지 10번째 행)은 앞 2프레임과 뒤 2프레임으로 분리한다.
총 12개 동작, 76프레임. 이미지 위에서 아래로, 각 행의 왼쪽에서 오른쪽으로 재생한다.
분리한 각 동작도 각각 5회 재생한 뒤 1초 대기한다.
