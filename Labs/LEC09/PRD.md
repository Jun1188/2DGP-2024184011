# 소닉 애니메이션 뷰어 PRD

- 개발 위치: `Labs/LEC09/` (저장소 루트 기준)
- 개발 브랜치: `feature/sonic-animation-viewer`
- 요구사항 원본: [PRE-PRD.md](PRE-PRD.md) (`Labs/LEC09/PRE-PRD.md`)

## 1. 목적

소닉 스프라이트 이미지의 모든 동작을 순서대로 재생하는 애니메이션 뷰어를 만든다.

## 2. 개발 조건

- 개발 언어: Python
- 라이브러리: pico2d
- 구현 파일: sonic_animation_viewer.py
- 구현 구조: Python 단일 파일
- 이미지: sonic-sprite.png

## 3. 기능 요구사항

### 3.1 동작 재생

- 이미지에 포함된 모든 동작을 재생한다.
- 각 동작의 전체 프레임을 순서대로 재생한다.
- 한 동작을 5회 반복한 뒤 1초 동안 대기한다.
- 대기가 끝나면 다음 동작을 재생한다.
- 마지막 동작의 재생과 대기가 끝나면 첫 동작으로 돌아간다.
- 사용자가 종료할 때까지 위 순서를 반복한다.

### 3.2 화면 표시

- 소닉이 화면에서 잘 보이도록 확대하여 표시한다.
- 확대할 때 이미지의 가로·세로 비율을 유지한다.
- 각 프레임에서 인접한 동작의 이미지가 섞이지 않도록 한다.

## 4. 구현 기본값

아래 값은 원본에 없는 세부사항을 보완한 구현 기본값이다. 프레임 표는 1단계 이미지 분석으로 확정했다. 이미지 크기는 399 × 525 픽셀이고 총 12개 동작, 76프레임이다. 정확한 프레임 좌표는 구현 파일의 ACTIONS에 기록한다.

### 4.1 화면 및 배치

| 항목 | 기본값 |
| --- | --- |
| 창 크기 | 800 × 600 픽셀 |
| 화면 좌표 | 왼쪽 아래가 (0, 0), 오른쪽 위가 (800, 600) |
| 배경 | 흰색, 매 프레임 화면 초기화 |
| 소닉 배치 | 수평 중심 x = 400, 발 기준선 y = 180 |
| 확대 배율 | 원본 프레임의 가로·세로를 각각 3배 (기존 표시 크기의 1/2) |
| 위치 보정 | 프레임 영역의 아래쪽 중앙을 발 기준선에 맞춘다. 점프 중에는 발 기준선에 점프 높이를 더한다. |
| 크기 변경 | 동작 전환 시에도 확대 배율 3배 유지 |

### 4.2 시간 및 재생 상태

| 항목 | 기본값 |
| --- | --- |
| 애니메이션 속도 | 모든 동작 10 FPS, 프레임당 0.1초 |
| 화면 갱신 목표 | 60 FPS, 루프 대기 기본값 1/60초 |
| 시간 계산 | 실제 경과 시간을 누적하여 프레임 진행과 대기를 계산 |
| 시작 상태 | 첫 동작, 프레임 인덱스 0, 완료 반복 횟수 0 |
| 반복 1회 | 첫 프레임부터 마지막 프레임까지 각각 0.1초 표시 |
| 동작 반복 | 정확히 5회 |
| 동작 사이 대기 | 1.0초, 해당 동작의 마지막 프레임 유지 |
| 다음 동작 전환 | 프레임 인덱스와 완료 반복 횟수를 0으로 초기화 |
| 마지막 동작 이후 | 1.0초 대기 후 첫 동작으로 전환 |

대기 중에도 화면 갱신과 종료 입력 처리를 계속한다. 1초 동안 전체 프로그램을 멈추는 방식은 사용하지 않는다.

### 4.3 프레임 구성 및 순서

- 이미지 위에서 아래로, 각 행에서는 왼쪽에서 오른쪽으로 재생한다.
- 10개 행을 12개 동작으로 구분한다. 8번째 행은 6+2프레임, 10번째 행은 2+2프레임으로 분리한다.
- 제목, 출처 문구, 하단의 다른 캐릭터 그림은 재생 대상에서 제외한다.
- 동작 이름은 의미를 추측하지 않고 `action_01`부터 `action_12`까지 사용한다.
- 프레임 인덱스는 동작마다 0부터 시작한다.

| 동작 | 이미지 내 행 | 프레임 수 | 프레임 인덱스 |
| --- | --- | --- | --- |
| action_01 | 소닉 첫째 행 | 11 | 0~10 |
| action_02 | 소닉 둘째 행 | 12 | 0~11 |
| action_03 | 소닉 셋째 행 | 6 | 0~5 |
| action_04 | 소닉 넷째 행 | 9 | 0~8 |
| action_05 | 소닉 다섯째 행 | 6 | 0~5 |
| action_06 | 소닉 여섯째 행 | 6 | 0~5 |
| action_07 | 소닉 일곱째 행 | 6 | 0~5 |
| action_08 | 소닉 여덟째 행 앞부분 | 6 | 0~5 |
| action_09 | 소닉 여덟째 행 뒷부분 | 2 | 0~1 |
| action_10 | 소닉 아홉째 행 | 8 | 0~7 |
| action_11 | 소닉 열째 행 앞부분 | 2 | 0~1 |
| action_12 | 소닉 열째 행 뒷부분 | 2 | 0~1 |

이미지는 균일한 격자가 아니다. 고정 셀 크기로 나누지 않고, 각 프레임을 `(left, top, width, height)` 정수 픽셀 좌표로 기록한다. 원본 좌표의 기준은 이미지 왼쪽 위다. pico2d에 전달할 아래쪽 좌표는 `bottom = image_height - top - height`로 변환한다.

1단계에서 행별 영역과 픽셀 분포를 분석하여 프레임 좌표와 수량을 정리했다. 시각적 잘림 여부는 사용자 실행 테스트에서 확인한다. 인접 프레임, 제목, 출처 문구가 잘라내기 영역에 포함되지 않아야 한다. 확정한 프레임 목록은 `sonic_animation_viewer.py` 안에 저장한다.

### 4.4 입력 및 종료

| 입력 | 동작 |
| --- | --- |
| 실행 | 첫 동작부터 자동 재생 |
| Esc 키 누름 | 루프 종료 및 창 닫기 |
| 창 닫기 버튼 | 루프 종료 및 창 닫기 |
| 그 외 키보드·마우스 입력 | 재생 상태 변경 없음 |

기본 기능에는 수동 동작 선택, 일시정지, 속도 변경, 이동 입력을 포함하지 않는다.

### 4.5 파일 및 오류 처리

- 구현 파일 위치: `Labs/LEC09/sonic_animation_viewer.py`.
- 이미지 위치: `Labs/LEC09/sonic-sprite.png`.
- 이미지 경로는 Python 파일이 있는 폴더를 기준으로 계산한다.
- Python 코드는 하나의 파일에 작성하고 UTF-8 BOM으로 저장한다.
- 이미지가 없거나 읽기에 실패하면 파일 경로와 오류 내용을 콘솔에 표시하고 종료한다.
- 실행 테스트는 사용자에게 맡긴다. 위 기본값은 실행으로 검증된 결과가 아니다.

### 4.6 자동 위치 이동

이미지의 동작 형태를 기준으로 아래 이동 규칙을 적용한다. 동작 번호는 1부터 센다.

| 동작 | 위치 이동 |
| --- | --- |
| action_02, action_03, action_06, action_07 | 달리기: 오른쪽으로 120픽셀/초 |
| action_05 | 구르기: 오른쪽으로 120픽셀/초 |
| action_04, action_08 | 점프: 수직 상승 후 착지 |
| action_01, action_09, action_10, action_11, action_12 | 현재 위치 유지 |

- 캐릭터 크기는 이전 6배 표시의 절반인 3배다.
- 수평 중심의 이동 구간은 x = 60~740이다. 오른쪽 경계를 넘으면 왼쪽으로 이어진다.
- 다음 동작은 이전 동작의 종료 x 좌표에서 시작한다.
- 점프는 동작의 1회 재생을 하나의 궤적으로 사용하며, 5회 반복하면 5회 점프한다.
- 점프의 발 기준선은 y = 180, 최고점은 y = 320이다.
- 점프 진행률 p(0~1)에 대해 높이는 `4 * 140 * p * (1 - p)`로 계산한다.
- 1초 대기 중에는 수평 이동을 멈추고 점프는 지면에 착지한 상태를 유지한다.
- 위치는 실제 경과 시간과 재생 진행률에 따라 갱신한다. 사용자 이동 입력은 추가하지 않는다.

## 5. 단계별 개발 계획

한 번에 전체 기능을 작성하지 않고 단계별로 구현한다. 각 단계가 완료되면 해당 단계의 변경 사항을 커밋한다.
아래 단계 구분과 완료 조건은 제안이며, 개발 전에 확정한다.

| 단계 | 작업 | 완료 조건 |
| --- | --- | --- |
| 1 | 스프라이트 분석 | 모든 동작과 프레임 영역 정리 |
| 2 | 기본 화면 구성 | 창 생성 및 소닉 한 프레임 확대 표시 |
| 3 | 단일 동작 재생 | 한 동작의 프레임 순차 재생 |
| 4 | 반복 및 대기 구현 | 동작 5회 재생 후 1초 대기 |
| 5 | 전체 순환 구현 | 모든 동작 순차 재생 및 무한 반복 |

각 단계의 구현 내용을 설명하고 커밋한다. 빌드는 수행하지 않으며, 실행 테스트는 사용자에게 맡긴다.

## 6. 사용자 확인 기준

- 모든 동작이 누락 없이 재생된다.
- 각 동작은 정확히 5회 반복된다.
- 동작 사이에 1초 대기가 적용된다.
- 마지막 동작 이후 첫 동작으로 돌아간다.
- 소닉이 충분히 크게 표시되고 화면 안에 들어온다.
- 프레임에 인접 이미지가 섞이지 않는다.
- 창을 정상적으로 종료할 수 있다.
